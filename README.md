# 小葵與阿公的煉金冒險：點石成金的真相

台灣國二下理化第一章《化學反應與化學計量》互動教材。本 repo 僅收錄這個單元。

## 五張探索卡片

1. 原子量、分子量與莫耳：先教觀念，再組分子與換算
2. 化學反應常見現象：樣本架與可直接操作的實驗台（鎂燃燒、硫酸銅受熱、沉澱、氣體）
3. 化學反應式：書寫示範、係數配平與原子核對
4. 化學計量：先看 68 g 過氧化氫的分步例題，再自由調整，下方題目練習
5. 質量守恆：真實器材式秤量、混合、開放與密閉對照

四頁講義的觀念整合於操作、圖解與 22 題分步計算練習；科學名詞提供定義、例子和單位。進度保存在瀏覽器本機。

### 實驗室操作與重量對照

質量守恆實驗台提供小蘇打與醋酸的開放、密閉對照。學生可點選或拖曳放入材料，連接集氣袋，記錄反應前重量，再混合並觀察電子秤、氣泡與集氣袋。重量面板顯示反應前後總重與逸散氣體重量；相同條件和用量不重複紀錄，完成相同用量的開放與密閉實驗後可比較結果。

計量工坊上方為自動示範：改變反應、產物或用量，即時顯示三步計算與理論產量。下方三個小關卡與小試身手保留學生作答。

### 學生操作路徑

每站依「完成指定操作 → 答對本站小試身手」計算完成；不需要先作答猜想。補充圖解、22 題計算與故事結局均為選修，不影響五站進度。完成條件集中於 `learning-progress.js`，操作證據會儲存在瀏覽器。舊版僅由開頁或觀看示範留下的完成旗標，不會當作親手操作的證據；原有作答與可驗證的配平、計算、秤量紀錄仍保留。

放大模式將同一份操作元件移入視窗，返回後保留狀態。第一站的三個概念逐步呈現；滴加鹽酸看到氣泡即可比較前後變化，12 滴僅表示模擬滴管容量。

### 第一站的互動

原子量頁籤將碳-12、氫-1、氧-16 並排，以緊密的原子核與繞行電子呈現行星模型，直接顯示質子、中子數量與原子量。電子數分別為 6、1、8，並配合減少動態設定；模型尺寸與電子軌道僅為示意。分子量頁籤沿用分子鍊成陣。莫耳頁籤可切換水分子、碳原子、氫氣分子；各沿用七段拉遠與 1～10 mol 的份量操作。碳以單顆原子示意，氫氣以兩個氫原子組成的 H₂ 分子示意；同為 1 mol 時粒子數相同，質量分別約 18、12、2 g。切換物質會回到起始視野與 1 mol；第七段巨觀畫面下方顯示滑桿與加減按鈕，可調整莫耳數並立即看到質量變化。巨觀畫面對應水、碳與密閉容器內的無色氫氣；碳與氫氣瓶採寫實圖像，圖片同時包含於離線檔。模型不代表真實容器體積。水的探索從多個水分子開始，滾輪每向下滾一下便拉遠一段，看到更多水分子；第七下把粒子框成一包，每包標示 1 mol（約 6.02 × 10²³ 個粒子），旁邊顯示對應的物質與天平。增加莫耳數會增加相同大小的包數，2 mol 兩包、3 mol 三包，最多 10 包，質量同步更新；水每包約 18 g，碳每包約 12 g，氫氣每包約 2 g。向上可拉近，也支援視野滑桿與鍵盤。改變視野不改變用量，另有 1～10 mol 的份量滑桿。模型不按真實尺寸或粒子總數繪製。

### 第三站的配平流程

反應式先以反應前、反應後的物質並排呈現；狀態符號放在可展開的說明內。學生可切換「看一題示範／自己配平」，示範以粒子分組解釋 2 的意義，練習時係數直接放在化學式前方。提示依目前原子數更新，標示可調整的物質；完成四題後可直接前往測驗。鎂帶實驗採寫實實驗室背景，火焰與匙內材料由反應進度驅動，並提供材料放大觀察；照片包含於離線檔。

### 第二站的動手實驗

延續 ch2 02 卡片的樣本架與同一實驗台，樣本可點選或拖入。鎂帶與含水硫酸銅須先取樣，才能點燃酒精燈；點燈可開始／繼續加熱，熄火可暫停，完成後自動熄火。兩種無色溶液可分別拖入中央燒杯；鹽酸滴管可拖曳定位、按住滴加、放開停止。反應完成後顯示前後對照，已完成的實驗保存在觀察表與既有學習進度。重做單一實驗不清除其他觀察紀錄；切換或離開操作台會停止加熱與連續滴加。只修改 ch1，ch2 維持原樣。
