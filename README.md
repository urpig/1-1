# 小葵與阿公的煉金冒險：點石成金的真相

台灣國二下理化第一章《化學反應與化學計量》互動教材。本 repo 僅收錄這個單元。

## 五張探索卡片

1. 原子量、分子量與莫耳：先教觀念，再組分子與換算
2. 化學反應常見現象：圖解教學，移除原本的四實驗互動工作台
3. 化學反應式：書寫示範、係數配平與原子核對
4. 化學計量：上方自動示範，下方題目練習
5. 質量守恆：真實器材式秤量、混合、開放與密閉對照

四頁講義的觀念整合於操作、圖解與 22 題分步計算練習；科學名詞提供定義、例子和單位。進度保存在瀏覽器本機。

## 本機執行

需要 Node.js 24 或更新版本，無需安裝額外套件。

```sh
node server.mjs
```

開啟 http://127.0.0.1:4176/chemistry/index.html 。

## 建置與測試

```sh
node build-chemistry.mjs
node --test tests/chemistry.test.mjs
```

離線檔案輸出至 `outputs/chemistry-adventure.html`。`release/` 與 `outputs/` 不納入版本控制。

## 靜態網站

公開網址：https://urpig.github.io/ch1/ 。不需登入即可查看與操作。

根目錄 `index.html` 會導向 `dist/chemistry/index.html`，GitHub Pages 由 `main` 分支根目錄提供服務。

發布前先執行建置；建置會依程式與樣式內容更新資源版本與 import map，避免新版頁面混用舊快取。請將更新後的 `dist/chemistry/index.html` 一起提交。

## 視覺與互動

視覺精修包含深綠導覽、手札封面、五站探索地圖、卡片內四步導引、閱讀位置提示與實驗控制面板。樣式位於 `dist/chemistry/polish.css`，導引互動位於 `polish.js`；科學計算仍使用原有核心。

執行 `node build-chemistry.mjs` 會將新樣式與導引一併打包到 `outputs/chemistry-adventure.html`，可以直接開啟離線操作。


### 實驗室操作與重量對照

質量守恆實驗台提供小蘇打與醋酸的開放、密閉對照。學生可點選或拖曳放入材料，連接集氣袋，記錄反應前重量，再混合並觀察電子秤、氣泡與集氣袋。重量面板顯示反應前後總重與逸散氣體重量；相同條件和用量不重複紀錄，完成相同用量的開放與密閉實驗後可比較結果。

計量工坊上方為自動示範：改變反應、產物或用量，即時顯示三步計算與理論產量。下方三個小關卡與小試身手保留學生作答。
